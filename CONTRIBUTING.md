# Contributing

SignalGraph v1 is a verified release candidate. Contributions must remain within published project scope unless the maintainer explicitly activates a later version. SignalGraph is source-available under the [Hecavex Internal Use and Security Research License 1.0](LICENSE), not an open-source license.

Before proposing a change:

1. Open an issue before beginning a substantial change.
2. Keep changes focused and do not introduce future-version features early.
3. Include appropriate tests, documentation, migration guidance, and security review.
4. Run backend tests and lint plus frontend tests and build before submitting a pull request.
5. Never include credentials, live sensitive intelligence, or unsafe active-collection behavior.

Issues, security reports, and documentation corrections are welcome. Source-code contributions cannot be accepted or merged until Deividas Lis and the contributor agree to separate written contribution terms. Opening a pull request does not transfer ownership or grant the project a license to the contribution.

For questions and early proposals, prefer [GitHub Discussions](https://github.com/Hecavex/signalgraph/discussions). Report vulnerabilities only through [GitHub Security Advisories](https://github.com/Hecavex/signalgraph/security/advisories/new), never through a public issue.
