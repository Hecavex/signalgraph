# Support

SignalGraph is a self-hosted, source-available project maintained by Deividas Lis through Hecavex.

## Where to ask

- Use [GitHub Discussions](https://github.com/Hecavex/signalgraph/discussions) for setup questions, deployment experiences, collector configuration, and early ideas.
- Use [GitHub Issues](https://github.com/Hecavex/signalgraph/issues) only for reproducible defects or focused proposals that follow an issue form.
- Use [GitHub Security Advisories](https://github.com/Hecavex/signalgraph/security/advisories/new) for vulnerabilities or other sensitive security reports.
- Visit [hecavex.com](https://hecavex.com) or contact [Deividas Lis on LinkedIn](https://www.linkedin.com/in/deilis) for licensing outside the public terms.

Community support is best effort. Do not post credentials, API keys, private threat intelligence, customer data, or internal infrastructure details.
